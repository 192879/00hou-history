# V2 Android 测试记录

## 已自动验证

- V1 六阶段游戏仍可从开局运行到结局。
- 31 届档案、24 个原有天赋仍可读取。
- 公元前 1 年推进后直接进入公元 1 年，不生成公元 0 年。
- 确定性随机数保存状态后能够恢复相同序列。
- 快进按年执行经济、健康和时间线结算。
- 自动档及三个手动档能够写入、读取和整包导入导出。
- V1 存档迁移为只读人生档案，原始 JSON 保留。
- Capacitor 构建产物包含本地 `index.html` 和共享模块，无网可加载基础游戏。
- 60 个天赋、20 个职业和4个地区数据满足最低内容数量。
- 古代角色无法进入程序员等现代职业。
- 历史事件按年份与地区过滤，不会把中国地区事件直接套给欧洲角色。
- 固定种子角色能够从出生逐年推进到死亡，过程中属性、经济和技能没有 `NaN` 或无穷值。
- 相同待决事件存档恢复后会得到完全相同的事件和选择结果，不可通过刷新重抽。

## 真实浏览器端到端测试

`pnpm test:e2e` 使用 412×915 的 Microsoft Edge Chromium 视口实际点击：开始人生、选择三个天赋、进入人生、推进一年、刷新页面、读取自动档。已验证恢复年龄为1岁且页面没有横向溢出。

## Android 仪器测试

`ExampleInstrumentedTest` 验证应用 ID，并从 APK 资源中读取本地首页，证明游戏入口实际打包在 APK 中。

## 当前环境限制

当前开发主机未安装 JDK、Android SDK、Gradle 或模拟器，因此尚未在本机执行安装、冷启动、强制结束进程恢复和系统文件选择器测试。GitHub Actions 会使用 JDK 21、Android SDK 36 和 Gradle Wrapper 构建真实 Debug APK。首次云端构建成功后仍需在安卓设备或模拟器执行安装验收。
